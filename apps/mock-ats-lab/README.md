# apps/mock-ats-lab

Deterministic local ATS fixture web app
(docs/MASTER_IMPLEMENTATION_SPEC.md §5.1, §8.2): native and
framework-controlled inputs, dynamic and multipage forms, iframes, shadow
DOM, uploads, honeypots, validation errors, receipts, CAPTCHA-pause
placeholders, and prompt-injection fixtures. No automated test may submit to
a live employer.

This is a workspace slot created by the M00-W02 scaffold. The lab is built
in M02-W03; adding fixture forms earlier would broaden the scaffold package.
No build/test scripts exist here yet by design.
